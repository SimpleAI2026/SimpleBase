命令：`object list|upload|delete|presign`。`key` 是项目内相对路径，不要带项目前缀。

## list / presign

```
simplebase object list --prefix docs/
simplebase object presign --key docs/readme.md
```

`--prefix` 可省略（列出全部，最多 1000 条）。`presign` 在助手模式下只返回 `key` 与 `expires_at`，不返回 URL：不要向用户索要或转述链接，让用户在控制台下载。

## upload

助手模式不能读宿主机文件，`--file` 的值只能是 `-`，内容放入工具参数 `stdin`：

```
simplebase object upload --key docs/readme.md --file -    ← 文件内容放 stdin
```

二进制内容改用 `--content-base64 <base64>`，此时 `--file` 仍需给出（填 `-`）。内容受 `stdin` 256KiB 上限约束，更大的文件无法经助手上传，如实告诉用户。

## delete

```
simplebase object delete --key docs/readme.md   ← 需要确认
```

`object delete` 需要界面确认；headless 返回 `confirmation_unavailable`，不要重试。

## key 规则与错误码

- key 非空、不以 `/` 开头、不含 `..` 与 `.` 路径段和反斜杠、不超过 1024 字节；违规返回 `invalid_file_key`，改 key 后再试。
- `file_not_allowed`：`--file` 传了路径，改用 `--file -` 并把内容放 `stdin`。
- `writer_unavailable`：实例只读，不能上传或删除。
