# Minimalist / Editorial Style Overlay

Use when the user asks for minimal, clean, editorial, document-like, or "Notion/Linear-like" calm. Overlay on top of the core rules.

## Character
Warm monochrome canvas, typographic contrast does the work, flat surfaces, color only as tiny semantic accents.

## Spec (starting values — adapt)
- **Canvas:** white or warm off-white (≈ `#FBFBFA`/`#F7F6F3`); surfaces barely different.
- **Text:** off-black (≈ `#111`–`#2F3437`), muted secondary (≈ `#787774`); body line-height ~1.6.
- **Borders:** hairline, very light (≈ `#EAEAEA` or `rgb(0 0 0 / .06)`). Borders replace shadows.
- **Accents:** desaturated pastels for tags/badges only, each paired with a darker same-hue text.
- **Type:** neutral sans for UI + editorial serif for large headings/quotes (tight tracking, line-height ~1.1) + mono for metadata/shortcuts.
- **Radius:** crisp — 4–6px buttons, ≤ 8–12px cards, pills for tags.
- **Shadows:** none or nearly invisible. **Gradients:** none.
- **Buttons:** solid dark primary, light text, no shadow; hover = slight tone shift.
- **Layout:** generous padding, asymmetric bento grids with flat bordered cells, accordions as divider-separated rows, `<kbd>`-style shortcut chips.
- **Motion:** minimal, short opacity/translate fades.

## Avoid
Heavy shadows, glass, gradients, saturated brand floods, emoji, oversized rounded corners, decorative illustrations without purpose.
