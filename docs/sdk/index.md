# JavaScript SDK

`@simplebase/sdk` 用一把 API Token（Bearer Key）调用 SimpleBase HTTP `/v1`，覆盖 **SQL、文档集合、S3**。浏览器与 Node 18+（原生 `fetch`）共用同一套 API。
