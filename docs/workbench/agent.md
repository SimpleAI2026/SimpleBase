# 云助手概览

云助手把大模型与项目内工具组合，按模块管理配置；控制台「工作台 → 云助手」可以创建会话，使用 `@` 选择 Agent 并查看工具调用。Agent 使用你当前项目的权限，不会自动获得跨项目访问能力。

## 何时使用

需要用自然语言探索数据库、文件或运行日志时，可在会话中让 Agent 调用只读工具；需要在独立 Linux 环境执行代码时，给 Agent 启用云沙盒模块。云沙盒命令与文件留在 VM 内，不等同于修改 SimpleBase 的 SQL、对象存储或系统库。

## 基本流程

1. 在控制台选择普通项目，打开「云助手」，检查所需模块和工具是否启用。
2. 新建会话后默认已选中「通用助手」，直接输入问题发送即可；空会话里会给出几条提示词，点一下即可填入输入框。要改用别的助手，在左侧点选，或输入 `@` 点名助手（如 `@Database`、`@云函数助手`）。`@` 只用于点名助手，技能由助手本身决定，不能通过 `@` 选择。
3. 对话中的工具调用、结果与运行状态会随会话显示；按需取消正在运行的任务。需要写数据的操作会在对话里弹出行内确认卡，点「确认执行」放行、「取消」或 `Esc` 终止。
4. 需要周期执行提示词时用 Agent 定时调度；需要固定入参触发 Go 函数时改用[定时任务](/docs/automation/cronjob)。

## API 概览

`GET /v1/projects/:projectID/agents/modules` 列出可选模块。管理 Agent 使用 `/agents`；会话和消息使用 `/agent-threads`；`PATCH /agent-threads/:threadID` 可重命名，`GET /agent-threads/:threadID/runs` 查询耗时、token 和工具调用次数；调度用 `/agent-schedules`。创建 run 使用 `POST /agent-threads/:threadID/runs`，实际回答以流式结果返回。完整工具规则见[工具与模块](/docs/workbench/agent-tools)，模型与端到端验证见[联调与验收](/docs/workbench/agent-e2e)。

## 权限与边界

读取资源需要 `database:read`；修改 Agent 配置、会话等操作分别要求路由对应权限。Agent 的数据库和 S3 工具只读；沙盒工具只作用于隔离 VM。不可将不可信的上下文视为操作授权。

## 使用场景

### 场景一：用自然语言查数据

背景：想知道项目里有哪些数据库、某张表有哪些列，但不想先打开 SQL 工作台。

1. 打开「云助手」，选择带数据库模块的 Agent，新建会话。
2. 输入 `@` 选择该 Agent，发送：`列出项目里的数据库，并告诉我 orders 表有哪些列`。
3. 对话里会出现工具调用卡片（例如列库、读结构），结果随回答一起展示。

预期：Agent 只调用只读工具，不会修改数据。需要写入时请回到「数据管理」或使用 API。

### 场景二：用日志排查报错

背景：监控大盘上错误率升高，需要快速定位原因。

发送：`查最近的 error 级别日志，按出现频率总结前三类问题`。Agent 通过日志工具检索项目日志并归纳。要核对原始记录，再到[日志管理](/docs/ops/logs)按级别与时间过滤。

### 场景三：在沙盒里跑一段脚本

背景：需要对一批数据做临时清洗，但不希望动 SimpleBase 的库表。

前置条件：部署时已启用云沙盒，并给 Agent 启用沙盒模块（见[工具与模块](/docs/workbench/agent-tools)）。发送：`在沙盒里用 python 统计 /workspace/data.csv 的行数`。命令与文件只在隔离 VM 的 `/workspace` 内生效，用完后可到「云沙盒」页面查看并清理。

### 场景四：让 Agent 定时做周报

背景：每周一早上需要一份项目运行概览。

在 Agent 的调度设置里新建定时任务，填写周期与提示词，例如 `汇总最近 7 天的请求量、错误日志与新增对象数量`。对应接口是 `/agent-schedules`。固定入参地调用云函数请改用[定时任务](/docs/automation/cronjob)。

### 场景五：多个 Agent 协作

每个会话只绑定一个助手，一条消息也只能点名一个助手（点名其他助手会提示切换）。需要多个能力时，切换到对应 module 的助手再发一次；`@` 不能用来挑技能。

## 常见问题

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 没有可选的沙盒工具 | 部署未启用云沙盒 | 先查 `GET /v1/projects/:projectID/agents/modules`，以返回的模块为准 |
| 回答里没有真实数据 | Agent 未启用对应工具，或模型未发起工具调用 | 在 Agent 配置里检查 `tool_ids`，并确认当前项目不是系统项目 |
| 回复中途停止 | 用户取消或网络中断 | 已生成内容会保留，可点击「重试」继续 |
