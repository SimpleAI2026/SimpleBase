# 运维

本模块覆盖日志排查、实例部署、生产配置和故障处理。

| 文档 | 内容 |
|---|---|
| [日志与审计](./logs.md) | 日志筛选、保留期与审计边界 |
| [部署与故障处理](./deployment.md) | 单写实例、生产配置与 Runbook |
| [备份与恢复](./backups.md) | 项目快照、定时备份、下载与恢复验收 |
| [迁移指南（历史存档）](./migration.md) | 仅供维护旧版本参考 |

控制台「API 预览」位于运维分组：`/console/api-preview` 从真实路由表生成 OpenAPI 3.0.3、cURL/JS/Go 示例并试跑；写请求必须确认，流式与下载端点不试跑，示例不包含真实令牌。

控制台「监控大盘」属于工作台模块，见 [监控大盘](/docs/workbench/dashboard)。生产部署请先阅读部署指南中的安全、端口与数据目录约束。
