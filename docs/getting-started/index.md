# SimpleBase 入门

SimpleBase 是面向 AI / 数据基础设施的控制台：在同一项目下管理 **DuckLake 数据库**、**S3 对象存储**、**云 Agent** 与运维日志。

## 你能做什么

- **监控大盘**：查看项目运行概况与配额
- **数据库管理**：创建库、跑 SQL、管理集合与文档
- **S3 对象存储**：浏览与管理对象（AWS S3 协议兼容）
- **云 Agent**：按模块配置 Agent，在对话里 `@` 调度只读工具
- **设置 / 日志**：模型与主题、审计与运行日志
