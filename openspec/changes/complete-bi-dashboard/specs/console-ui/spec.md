# Spec Delta

## ADDED Requirements

### Requirement: 看板视觉层级

看板 SHALL 按「总量 → 趋势 → 分类 → 数值分布」组织默认卡片，KPI 与图表分区呈现；首屏不得以装饰性内容挤压数据。窄屏 MUST 提供可用的卡片浏览与操作入口，不出现横向溢出。

#### Scenario: 默认看板
- **WHEN** 用户首次打开一个集合或 SQL 表
- **THEN** 默认卡片覆盖总量、趋势、分类与数值分布，顺序稳定且可解释

#### Scenario: 窄屏浏览
- **WHEN** 视口宽度为手机尺寸
- **THEN** 卡片单列显示，操作按钮可点，无横向滚动

### Requirement: 图表可读性与数值表达

图表 SHALL 区分「参与统计行数」与物理扫描量，截断结果 MUST 在卡片内标注；不可累加度量（avg / min / max / distinct）MUST NOT 合并为「其他」或计算占比；空值 MUST 与 0、空串、false 区分显示。

#### Scenario: 截断的分类结果
- **WHEN** 分类数量超过取数上限
- **THEN** 卡片标注「部分分组」，不展示为完整占比

#### Scenario: 不可累加度量
- **WHEN** 用户对 avg 度量选择饼图
- **THEN** 系统拒绝或改用排名条形图，不合并「其他」

### Requirement: 看板产物导出与配置迁移

看板 SHALL 支持单图 PNG 与单图 CSV 导出、图表全屏、看板配置导出 / 导入。导出 MUST 标注当前筛选条件与是否截断；配置导入 MUST 校验字段与类型，覆盖既有看板前 MUST 二次确认。

#### Scenario: 导出截图
- **WHEN** 用户导出单图为 PNG
- **THEN** 图片包含标题与筛选摘要，截断时带有标注

#### Scenario: 导入配置
- **WHEN** 用户导入一个字段缺失的看板配置
- **THEN** 导入被拒绝并指出缺失字段，现有看板不变

### Requirement: KPI 环比与时间缩放

KPI SHALL 支持与上一个同长度时间窗对比的环比，取数失败时 MUST 隐藏环比而不是显示 0。时间维度图表 SHALL 支持小时 / 天 / 周 / 月 / 年桶切换与缩放；补桶范围 MUST 以服务端返回的桶为界，不推测截断之外的时间窗。

#### Scenario: 环比
- **WHEN** 用户查看最近 7 天新增 KPI
- **THEN** 显示相对上一个 7 天的变化；上一窗口无数据时显示不可用

#### Scenario: 缩放
- **WHEN** 用户在时间序列上拖动缩放
- **THEN** 图表与明细按当前窗口刷新，筛选条件保持
