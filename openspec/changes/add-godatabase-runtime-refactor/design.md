# Design

## 冻结契约

- 公开 API 与导出符号不变（新增只能内部化，删除需单独批准）。
- 对象键布局、manifest JSON 字段、`Spec` 六字段、DDL 与系统库最终态建表不变。
- 错误文本、错误顺序、事件顺序、取消语义与 `errors.Is` 恒等关系不变。
- 依赖方向保持 `registry → filedb/ducklake/cache/lease → blob → 根包 → sqlx`；根包不 import 子包。
- 不新增第三方依赖。

## 候选分层

| 层 | 候选 | 准入 |
| --- | --- | --- |
| 局部 | S-01 私有别名与无断言测试；S-02 路径校验共享；S-03 根包结果契约测试 | 零行为变化 |
| 流程 | F-01 快照内核、F-02 Flush 分段、F-03 Factory 策略与所有权、F-04 分页去重 | 先补特征测试 |
| 同步 | D-01 延迟计算、D-02 local-state 所有权、D-03 捕获/发布边界、D-04 prune 计划与动作 | 锁域不合并 |
| KV / CLI | K-01 删除收尾、K-02 Scan 参数、K-03 Hash 元数据探测、C-01 CLI 拆分 | 各自 SQL 保留 |
| 资源 | R-01 Handle 关闭骨架、R-02 缓存扫描合并、R-03 singleflight 登记、R-04 ownerID 局部化 | flush 意图保留 |
| 暂缓 | Q-01 SQL 守卫结构统一 | 语义差异未证明可合并 |

## 验证

- 每批：`GOWORK=off go build ./... && go vet ./... && go test ./... -timeout 900s`，涉及并发加 `-race`。
- 性能候选：先留端到端基线（`bench`），单项前后对比；无法复现的收益不写入结论。
- 回填：每项记录「完成 / 部分 / 保留 / 取消」、实际命令与未验证边界；不预打勾。

## 回滚

只回退当前候选的改动；不整文件 restore、不 hard reset。拆文件后发现回归优先撤销逻辑变更；纯搬移是否保留按独立价值判断。
